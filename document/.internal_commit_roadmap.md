## 3. Feature Categorization Rules
1. **Security & Authentication Isolation:** All auth token entities, password hashing services, and authentication endpoints are grouped into Checkpoint 1 (`feature/auth-and-patients`).
2. **Billing & Invoice Workflows:** Financial calculation logic, PDF rendering, email dispatch endpoints, and receipt JSPs are grouped into Checkpoint 2 (`feature/billing-and-reports`).
3. **Automated Testing Suite:** REST API controller and Spring Data JPA test cases are isolated under Checkpoint 3 (`feature/frontend-and-testing`).
4. **Documentation Integrity:** Technical documentation, UML diagrams, report documents, and version control configuration belong to Checkpoint 4 (`feature/docs-and-db-architecture`).
5. **Remote Repository Synchronization:** Local feature branch commits and main branch merge history are synchronized to `origin` to fulfill GitHub assignment submission criteria (Task D).
